# Minecraft "All Items" Survival Checklist (Comprehensive)

> **Difficulty Tags for Web App Parsing:**
> * `[Common]` - Easy to obtain early game
> * `[Uncommon]` - Requires basic crafting, smelting, or exploration
> * `[Rare]` - Specific biomes, structures, or Nether progression
> * `[Epic]` - End dimension, heavy grinding, or specialized farms
> * `[Legendary]` - Boss drops, extreme RNG, or world-limited items
